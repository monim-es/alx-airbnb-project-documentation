# Airbnb Clone Backend – User Stories

This document outlines core user stories derived from the use case diagram. These stories guide the development of key backend features for the Airbnb clone platform.

---

## 🧑‍💻 User Registration & Authentication

**Story 1**  
**As a user**, I want to be able to register an account so that I can access the platform as a guest or host.

**Story 2**  
**As a user**, I want to log in securely using email/password or third-party providers (Google, Facebook) so that I can access my dashboard.

---

## 🏠 Property Listings (Host)

**Story 3**  
**As a host**, I want to create, update, and delete my property listings so that guests can view and book them.

---

## 🔍 Search & Booking (Guest)

**Story 4**  
**As a guest**, I want to search for properties by location, price, number of guests, and amenities so that I can find a place that suits my needs.

**Story 5**  
**As a guest**, I want to book a property for specific dates so that I can confirm my stay.

---

## 💳 Payments

**Story 6**  
**As a guest**, I want to securely pay for my bookings so that I can complete the reservation process.

**Story 7**  
**As a host**, I want to receive payouts automatically after a booking is completed so that I can earn from my listings.

---

## ⭐ Reviews and Ratings

**Story 8**  
**As a guest**, I want to leave a review and rating after my stay so that I can share my experience with others.

**Story 9**  
**As a host**, I want to respond to guest reviews so that I can engage with feedback and maintain my reputation.

---

## 🛠️ Admin Controls

**Story 10**  
**As an admin**, I want to manage users, listings, bookings, and payments so that I can monitor and moderate platform activity.
