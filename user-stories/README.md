# Airbnb Clone Backend

## 📌 Project Overview
This is the backend for an Airbnb-like rental marketplace, supporting user registration, property listings, bookings, payments, and reviews.

## 🚀 Features
- User registration & login (JWT + OAuth)
- Host property listings
- Guest search & booking
- Payment integration (Stripe/PayPal)
- Reviews and ratings
- Admin dashboard

## 📂 How to Use
1. Clone the repo  
2. Set up environment variables (`.env`)  
3. Run migrations  
4. Start the server  
5. Use Postman or frontend to test endpoints

## ✅ Requirements
- Python / Django or Flask
- PostgreSQL or MySQL
- Redis (optional for caching)
- Stripe or PayPal keys
